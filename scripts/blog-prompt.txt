Perform your twice-daily blog generation task using your highest reasoning capabilities (gemini-3.1-pro tier):
1. Review `frontend/data.ts` and `frontend/data/blogs` and select a topic based on ONE of the four highly monetizable strategies:
   - "X vs Y" comparison (e.g., Tool A vs Tool B for a specific audience).
   - "Best [Category] Tools" for a specific use-case (e.g., 5 Best AI SEO Tools for Agencies).
   - A step-by-step Data-Driven Workflow Tutorial combining multiple tools.
   - A Deep-Dive Single Tool Review of a tool not yet covered.
2. Conduct a **complete deep dive research** using web searches to gather accurate, in-depth data and insights. Do not just summarize marketing copy. 
3. Write a complete, in-depth analysis of this topic using the skills from the `claude-blog` plugin.
   - Use an "Answer-First" introduction.
   - Use hard data, not adjectives (e.g. "generated in 42 seconds").
   - Include a Key Takeaways box.
   - Use aggressive internal linking to existing tools/categories.
4. Write the new blog post in its own individual `.ts` file inside `frontend/data/blogs/` (and export/import it into `frontend/data/blogs/index.ts`).
5. Ensure the blog has a highly engaging, hookable, attention-grabbing title.
6. Generate an image for it using the `generate_image` tool (use gemini-3.1-pro-image if available). The image **MUST** be a "light, clean, and minimal editorial illustration". Use a soft, modern color palette with lots of negative space.
7. Run `npx tsx generate-sitemap.ts` to update the sitemaps.
8. Test the project by running `npm run build`. 
9. If the build passes, commit and push all changes to GitHub.
